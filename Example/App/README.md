# 手動確認のチェックリスト

自動テスト（`Library` の単体テスト、`AppUITests` の App Intents Testing）で確かめられないところを、人の手で確かめるための一覧。
上から順にやれば、第2章から第7章までの機能をひととおり触れる。

準備: アプリをインストールして一度起動する。初期データに戻したいときは、Shortcuts アプリには出ない `ResetMemosIntent` を
UI テストから呼ぶか、アプリを入れ直す（メモはメモリ内にしか無いので、アプリを終了すると消える）。

## Shortcuts アプリ（シミュレータでもできる）

- [ ] アクションの検索で「Siri AI Prototype」を探すと、「メモを追加」「メモを完了にする」「メモの優先度を変える」が出る
- [ ] 「メモを作成」（`CreateMemoIntent`）は出ない（`isAssistantOnly`）
- [ ] 「メモを追加」を実行すると「追加しました」の応答と、完了ボタン付きのスニペットが出る
- [ ] 同じタイトルでもう一度「メモを追加」を実行すると、別の名前を聞かれる
- [ ] スニペットの「完了」を押すと、アプリを開かずにメモが完了になる
- [ ] 「メモを削除」を実行すると、実行前に確認が出る。キャンセルするとメモがアプリに残っている
- [ ] 「アプリのショートカット」に、オレンジ色のタイルで「メモを追加」「メモを完了」が出る

## Spotlight（シミュレータでもできる）

- [ ] アプリでメモを追加してから、ホーム画面を下にスワイプしてタイトルを入れると、このアプリの結果として出る
- [ ] タグ（初期データの「買い物」）でも見つかる
- [ ] メモを削除すると、Spotlight の結果から消える

## Siri（実機）

- [ ] 「Hey Siri、Siri AI Prototypeにメモを追加して」→ タイトルを聞かれ、答えるとメモが増える
- [ ] 「Hey Siri、Siri AI Prototypeに優先度高のメモを追加」→ 優先度が高のメモが増える
- [ ] 「Hey Siri、Siri AI Prototypeで牛乳を買うを完了にして」→ 完了になる。応答にアプリ名が入っていない
- [ ] 画面を見ずに（ロック中など）実行すると、「〜をメモに追加しました」の長い方の応答が読み上げられる
- [ ] メモの詳細を開いたまま「これを完了にして」と言うと、そのメモが完了になる

## Siri AI Developer Preview（iOS 27.3 beta の実機。`siriAIPreview = true` でビルドする）

- [ ] 「Hey Siri、牛乳のメモの優先度を高にして」→ `SetMemoPriorityIntent` が呼ばれる
- [ ] 「Hey Siri、優先度が高い未完了のメモを探して」→ `FindMemosIntent` が呼ばれ、結果が読み上げられる
- [ ] 「Hey Siri、溜まったメモを整理したい」→ memo-triage の app skill に沿って、3件ずつ完了か優先度変更かを聞かれる。削除は提案されない
- [ ] 鍵付きの本文を聞くと、Face ID などの認証を求められる
- [ ] Siri AI がメモを見せるときに、`CardSnippet` のカードが出る
- [ ] Xcode の Siri Integration Advisor に指摘が出ていない
- [ ] `AppUITests/MemoSiriEvaluationTests.swift` の評価が流せる（SiriEvaluations があるときだけコンパイルされる）
