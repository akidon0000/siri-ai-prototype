## Build
Implement the conversation with Siri for Memo's intents.

- AddMemoIntent: return full / supporting responses with ProvidesDialog, and add requestValueDialog to title
- AddMemoIntent: only when a memo with the same title exists, ask for a different name with $title.requestValue
- Add DeleteMemoIntent and call requestConfirmation(dialog:) at the start of perform()
- Add sharedWith to MemoEntity, and return .shared from OwnershipProvidingEntity while it's shared
- Add a subtitle (done / not done) and an image to MemoEntity's displayRepresentation
- Make MemoSnippetView and MemoSnippetIntent (SnippetIntent), with a complete button that runs CompleteMemoIntent
- Add ShowsSnippetIntent to AddMemoIntent's result (keep ReturnsValue<MemoEntity>)
- Conform MemoEntity to SnippetRepresentableEntity and return a CardSnippet (it's an iOS 27.3 beta API, so add @available)
- Add a ProvidesDialog response to CompleteMemoIntent, and throw MemoIntentError (CustomLocalizedStringResourceConvertible) when the memo doesn't exist
- Follow the HIG guidance above for response text (no app name, works by voice alone)

## Run it and check
1. Unit tests: `cd ios/Library && xcodebuild test -scheme Library -destination 'platform=iOS Simulator,name=iPhone 18 Pro'`
   (You may change the simulator name to an iPhone you have, from `xcrun simctl list devices available`)
2. Build the app and launch it in Simulator:
   `cd ios/App && xcodebuild build -scheme SiriAIPrototype -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build`
   `xcrun simctl boot 'iPhone 18 Pro' ; open -a Simulator ; xcrun simctl install booted ios/App/build/Build/Products/Debug-iphonesimulator/SiriAIPrototype.app ; xcrun simctl launch booted com.akidon0000.SiriAIPrototype`
   After launching, take a screenshot with `xcrun simctl io booted screenshot` and check it.
3. Run "Add Memo" in the Shortcuts app and check that the response dialog and the snippet appear.
   Also run it twice with the same title and check that the second run asks for a different name.
4. Run "Delete Memo" and check that a confirmation appears before it runs. Also check on the app's screen that the memo remains if you cancel.
   If you have no tool that can operate the UI, walk the user through these steps and ask for the results.
5. CardSnippet is visible only on a device running the Siri AI Developer Preview. If you have no device, report only that it compiles.

When you're done, report in these three parts:
- What you made (files added or changed)
- What you confirmed by running it (commands run and their results, screenshots)
- What you couldn't confirm (with reasons). Don't write "it worked" for anything you didn't check
