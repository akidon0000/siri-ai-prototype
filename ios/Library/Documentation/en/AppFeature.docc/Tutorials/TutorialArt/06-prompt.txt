## Build
Add an implementation that passes Memo's context to Apple Intelligence.

- Conform MemoEntity to IndexedEntity and put tags in keywords in attributeSet
- Create MemoSpotlightIndexer, which calls indexAppEntities / deleteAppEntities on a named CSSearchableIndex
  (call it every time a memo is added, updated or deleted)
- Conform MemoQuery to IndexedEntityQuery and implement the two reindexing methods
- Add appEntityIdentifier(forSelectionType:) to the memo list, and an NSUserActivity appEntityIdentifier to the detail screen (MemoDetailView)
- Implement displayRepresentations(for:requestedComponents:) on MemoQuery
- Set appEntityIdentifiers when creating the due-date notification
- When a memo is added from the UI, donate CreateMemoIntent with IntentDonationManager.shared.donate
- Conform AddMemoIntent to PredictableIntent
- Conform MemoEntity to Transferable
- Add MemoVisualSearchQuery (IntentValueQuery, SemanticContentDescriptor)
- Add ShowMemoSearchResultsIntent (@AppIntent(schema: .visualIntelligence.semanticContentSearch)) for "More results"

## Run it and check
1. Unit tests: `cd ios/Library && xcodebuild test -scheme Library -destination 'platform=iOS Simulator,name=iPhone 18 Pro'`
   (You may change the simulator name to an iPhone you have, from `xcrun simctl list devices available`)
2. Build the app and launch it in Simulator:
   `cd ios/App && xcodebuild build -scheme SiriAIPrototype -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build`
   `xcrun simctl boot 'iPhone 18 Pro' ; open -a Simulator ; xcrun simctl install booted ios/App/build/Build/Products/Debug-iphonesimulator/SiriAIPrototype.app ; xcrun simctl launch booted com.akidon0000.SiriAIPrototype`
   After launching, take a screenshot with `xcrun simctl io booted screenshot` and check it.
3. After adding a few memos in the app, type a memo title into Spotlight search (swipe down) on the simulator's Home Screen.
   Check that the memo appears as a result from this app. Also check that it disappears after you delete the memo.
   If you have no tool that can operate the UI, walk the user through these steps and ask for the results.
4. In unit tests, check that indexAppEntities / deleteAppEntities are called when memos are added, updated and deleted (you may make the index replaceable).
5. Context from screens, notifications and visual intelligence can't be fully checked in Simulator. List the items you couldn't check in your report.

When you're done, report in these three parts:
- What you made (files added or changed)
- What you confirmed by running it (commands run and their results, screenshots)
- What you couldn't confirm (with reasons). Don't write "it worked" for anything you didn't check
