## Decisions to confirm
- Implement everything Siri-related with the App Intents framework only. Don't use SiriKit (Intents / IntentsUI / .intentdefinition)
- Migrating from SiriKit (CustomIntentMigratedAppIntent) isn't needed, because this repository has never used SiriKit
- After reading the tutorial, explain in your own words whether these two points match its content

## Run it and check
1. Run `grep -rn "import Intents\|\.intentdefinition" ios/` and confirm there's nothing SiriKit-related
2. Unit tests: `cd ios/Library && xcodebuild test -scheme Library -destination 'platform=iOS Simulator,name=iPhone 18 Pro'`
3. Build the app, launch it in Simulator and take a screenshot:
   `cd ios/App && xcodebuild build -scheme SiriAIPrototype -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build`
   `xcrun simctl boot 'iPhone 18 Pro' ; open -a Simulator ; xcrun simctl install booted ios/App/build/Build/Products/Debug-iphonesimulator/SiriAIPrototype.app ; xcrun simctl launch booted com.akidon0000.SiriAIPrototype`
   (You may change the simulator name to an iPhone you have, from `xcrun simctl list devices available`)
4. List the TODOs in ios/Library/Sources/Clients/MemoClient.swift and sort out what chapter 2 will implement

If the build or tests fail, fix the cause and run them again. If you can't fix it, report the error as is.
