If you can't open it, read ios/Library/Documentation/en/AppFeature.docc/Tutorials/02-app-intents-basics.tutorial.
Original documents to read alongside:
  - docs/apple-doc/app-intents/app-intents.md
The tutorial's MemoStore corresponds to MemoClient in Clients and LiveMemoClient in ClientsLive in this repository.

## Build
Add Memo's App Intents implementation to ios/Library.

- Clients/MemoClient.swift: define add / memos(for:) / recentMemos / memos(matching:) / complete on the MemoClient protocol
- ClientsLive/LiveMemoClient.swift: an implementation that keeps memos in an in-memory array
- Add MemoEntity (id, title, isDone) and MemoQuery (EntityStringQuery) to AppFeature
- Add MemoPriority (AppEnum: Low, Normal, High) to AppFeature
- Add AddMemoIntent (with parameterSummary) and CompleteMemoIntent to AppFeature
- Make a minimal memo list screen (MemoListView) in AppFeature so memos can be added and completed in the app
  (it's a screen for checking results by eye from chapter 3 on; it doesn't need to be fancy)
- Prepare a TestMemoClient in TestSupport that returns fixed data
- Write unit tests for the two intents and MemoQuery in AppFeatureTests

## Run it and check
1. Unit tests: `cd ios/Library && xcodebuild test -scheme Library -destination 'platform=iOS Simulator,name=iPhone 18 Pro'`
   (You may change the simulator name to an iPhone you have, from `xcrun simctl list devices available`)
2. Build the app and launch it in Simulator:
   `cd ios/App && xcodebuild build -scheme SiriAIPrototype -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build`
   `xcrun simctl boot 'iPhone 18 Pro' ; open -a Simulator ; xcrun simctl install booted ios/App/build/Build/Products/Debug-iphonesimulator/SiriAIPrototype.app ; xcrun simctl launch booted com.akidon0000.SiriAIPrototype`
   After launching, take a screenshot with `xcrun simctl io booted screenshot` and check it.
3. Open the Shortcuts app (it's in Simulator) and search for "Siri AI Prototype" in a new shortcut's action search.
   Check that the App Intents you added (Add Memo / Complete Memo) appear, and that running "Add Memo" returns a dialog.
   If you have no tool that can operate the UI (such as an iOS Simulator MCP), walk the user through these steps and ask for the results.
