## Build
For the Siri AI Developer Preview, expose Memo's actions that have no schema as tools.

- Don't add @AppIntent(.tool) to the schema-conforming CreateMemoIntent / UpdateMemoIntent / DeleteMemoIntent
- Add SetMemoPriorityIntent with @AppIntent(.tool), and fill in title / description / each @Parameter's description
- Add MemoSearch (@AppEntity(.generable), TransientAppEntity) and FindMemosIntent (@AppIntent(.tool)), which takes it
- Add a locked body (authenticationPolicy: .requiresLocalDeviceAuthentication) and
  an internal revision (visibility: .internal) to MemoEntity
- Add @ComputedProperty isOverdue / noteText (indexingKey: \.contentDescription) /
  listName (customIndexingKey), and @DeferredProperty collaboratorNames to MemoEntity
- Add a @DeferredProperty with indexingKey (attachmentText, \.textContent) to MemoEntity
- Make MemoListQuery an EnumerableEntityQuery, and donate SetMemoPriorityIntent when the priority is changed in the UI
- Add @available(iOS 27.3, *) to the tool types
- Add Skills.skillsbundle to the app target and write Skills/memo-triage/SKILL.md
- Don't combine indexingKey / customIndexingKey with internal properties (the caution on the IntentVisibility page)

## Run it and check
1. Unit tests: `cd ios/Library && xcodebuild test -scheme Library -destination 'platform=iOS Simulator,name=iPhone 18 Pro'`
   (You may change the simulator name to an iPhone you have, from `xcrun simctl list devices available`)
2. Build the app and launch it in Simulator:
   `cd ios/App && xcodebuild build -scheme SiriAIPrototype -destination 'platform=iOS Simulator,name=iPhone 18 Pro' -derivedDataPath build`
   `xcrun simctl boot 'iPhone 18 Pro' ; open -a Simulator ; xcrun simctl install booted ios/App/build/Build/Products/Debug-iphonesimulator/SiriAIPrototype.app ; xcrun simctl launch booted com.akidon0000.SiriAIPrototype`
   After launching, take a screenshot with `xcrun simctl io booted screenshot` and check it.
3. Check that it also compiles for devices:
   `cd ios/App && xcodebuild build -scheme SiriAIPrototype -destination 'generic/platform=iOS' -derivedDataPath build-device CODE_SIGNING_ALLOWED=NO`
   Skills.skillsbundle is validated at build time; if you get an error, fix SKILL.md's frontmatter (name matches the directory name, description is one line).
4. The Siri AI Developer Preview works only on an Apple Intelligence-capable device (development signing) or in internal TestFlight testing.
   Ask the user to check on a device ("Hey Siri, set the memo's priority to high" and so on) and to check the findings of Xcode's Siri Integration Advisor.
   Before asking, give them a list of the utterances to try and the screens to look at.

When you're done, report in these three parts:
- What you made (files added or changed)
- What you confirmed by running it (commands run and their results, screenshots)
- What you couldn't confirm (with reasons). Don't write "it worked" for anything you didn't check
