# Siri AI Tutorials

Tutorials for learning everything from SiriKit to Siri AI while building the Memo app's code. They live in the documentation of the `AppFeature` module.

@Metadata {
    @TechnologyRoot
}

## Overview

Start with <doc:SiriAITutorials> to follow the path SiriKit → App Intents → App Shortcuts →
Apple Intelligence/Siri AI → Siri AI Developer Preview (ToolIntent).
Paste the prompt at the end of each tutorial into Claude Code to have it implement the chapter,
build it and check it in Simulator.

Each tutorial's material is the original Apple Developer Documentation saved under `docs/apple-doc/`
in this repository (fetched with the `update-apple-siri-docs` skill).

Created by Opus 5.5 with Dan Akiyama ([@akidon0000](https://github.com/akidon0000))

If you find a mistake or something missing, feel free to open a PR at [akidon0000/siri-ai-tutorials](https://github.com/akidon0000/siri-ai-tutorials).
