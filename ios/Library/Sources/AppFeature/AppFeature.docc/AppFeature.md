# Siri AI Tutorials

SiriKit から Siri AI までを、Memoアプリのコードを組み立てながら学ぶチュートリアル。モジュール `AppFeature` のドキュメントとして置いている。

@Metadata {
    @TechnologyRoot
}

## Overview

まず <doc:SiriAITutorials> を読んで、SiriKit → App Intents → App Shortcuts →
Apple Intelligence/Siri AI → Siri AI Developer Preview (ToolIntent) の流れを理解する。
各チュートリアルの最後にあるプロンプトをClaude Codeに貼ると、その章の実装から
ビルド・シミュレータでの動作確認までを進められる。

各チュートリアルの教材は、このリポジトリの `docs/apple-doc/` 配下に保存してある
Apple Developer Documentation の原文（`update-apple-siri-docs` スキルで取得したもの）。
