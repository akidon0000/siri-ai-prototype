# Siri AI PoC

Siri / Apple Intelligence (Siri AI) 連携のPoC用モジュール `AppFeature` のドキュメント。

@Metadata {
    @TechnologyRoot
}

## Overview

このモジュールにはまだSiri関連の実装は入っていない。まずは
<doc:SiriAITutorials> を読んで、SiriKit → App Intents → App Shortcuts →
Apple Intelligence/Siri AI → Siri AI Developer Preview (ToolIntent) の流れを理解してから、
各チュートリアルの最後にあるプロンプトをコピーしてClaude Codeに実装を指示する。

各チュートリアルの教材は、このリポジトリの `docs/` 配下に保存してある
Apple Developer Documentation の原文（`update-apple-siri-docs` スキルで取得したもの）。
