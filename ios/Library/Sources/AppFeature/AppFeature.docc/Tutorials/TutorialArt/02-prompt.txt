Tutorial 2 (App Intentsの基礎) を読んで理解した。
ios/Library に Memo の App Intents実装を追加して。

- Clients/MemoClient.swift: Memo (id, title, isDone) の AppEntity と、MemoClient プロトコルに
  addMemo / listMemos / completeMemo を定義する
- ClientsLive/LiveMemoClient.swift: メモリ内配列で保持する実装
- AppFeature に AddMemoIntent / ListMemosIntent / CompleteMemoIntent の3つの AppIntent を追加する
- TestSupport に固定データを返す TestMemoClient を用意する
- AppFeatureTests に3つのIntentの単体テストを書く
